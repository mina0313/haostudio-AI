HAO Studio

상세페이지 AI 제작툴 인수인계 자료

이 폴더는 고객 작성폼과 내부 관리자툴을 함께 전달하기 위한 공유 패키지입니다. 처음 받는 분은 이 파일부터 확인하면 됩니다.

내부 관리자툴 열기 고객 작성폼 열기

고객에게 파일 하나만 따로 보낼 때는 customer-form-standalone.html을 보내세요. project-form.html만 단독 전달하면 디자인이 깨질 수 있습니다.

사용 흐름

  1. 고객이 project-form.html에서 제품 정보, 컨셉, 강점, 인증, 옵션, 참고 URL을 작성합니다.
  2. 내부 담당자가 index.html에서 고객 작성 내용 불러오기를 누릅니다.
  3. 업체명을 선택하면 고객 입력 내용이 상담 요약, 요청사항, 강조 요소, USP, 참고 링크로 자동 정리됩니다.
  4. 내부툴에서 A/B 시안 생성, 섹션 수정, 고객 발송 문안, 제작 전달 자료를 이어서 확인합니다.
